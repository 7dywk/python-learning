# Python Automation & Learning Repository

Hi! This repository is a collection of my Python projects, focusing heavily on test automation, web scraping, and API interactions. It serves as a practical workspace for developing scalable testing frameworks and learning core Python concepts.

## 📂 Project Structure

All main projects are located inside the **`python_study/`** directory:

* **`api_and_mocking/`** — Scripts for testing APIs and creating mock responses.
* **`basics/`** — Fundamental Python scripts and core programming exercises.
* **`data_parsing/`** — Web scraping scripts and data extraction tools.
* **`playwright_components/`** — Reusable UI components and Page Object Model (POM) implementations for automated testing.
* **`real_sites_tests/`** — Automated end-to-end (E2E) test suites executed against real-world web applications.
* **`test_data/`** — Datasets, fixtures, and configuration files used for data-driven testing.

## 🛠 Tech Stack & Skills
* **Language:** Python 3.11
* **Test Automation:** Playwright, API Testing, Page Object Model (POM)
* **Tools:** PyCharm, Git, GitHub
* **Focus Areas:** Quality Assurance (QA) Automation, Web Scraping, Data Processing
